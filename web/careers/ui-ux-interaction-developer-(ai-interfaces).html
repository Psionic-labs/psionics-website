UI/UX Interaction Developer (AI Interfaces)

Transform complex AI orchestrations and node-based data workflows into high-end, low-latency user interfaces and interactive canvases.

Apply here

Mission

Enterprise intelligence is useless if executives cannot control it. Most AI interfaces are ugly, slow, and poorly designed wrappers. Your job is to build the premium frontend layer for Psionics's deployments. You will design and code fluid, highly responsive canvases, real-time node graphs, and interactive dashboards that make running autonomous data pipelines feel like playing a video game. You prioritize strict layout logic, structural performance, and flawless micro-interactions.

Responsibilities

  • Engineer Interactive Canvases: Build complex layout architectures featuring canvas panning, absolute coordinate calculations, and node-based visualization components.

  • Optimize Data Streaming UI: Develop highly performant UI states that elegantly handle real-time token streaming, state mutations, and heavy client-side calculations without dropping below 60fps.

  • Maintain Design Systems: Translate high-fidelity Figma blueprints into pixel-perfect, production-grade React components using Tailwind CSS and tabular lining variables.

  • Choreograph Motion: Build custom, logic-driven animation sequences with Site Motion to clearly represent non-linear AI decision-making paths and backend processes.

Requirements

  • Interaction Portfolio: A verified portfolio demonstrating extreme control over complex web interactions, layout calculations, and fluid animations using Site Motion or raw CSS/JS.

  • Frontend Precision: Expert-level fluency in React, Next.js, and TypeScript. You must understand how to optimize rendering pipelines, manage complex local component states, and prevent unnecessary DOM re-renders.

  • Typography & Scale Obsession: You care about the details. You notice when borders are off by 0.5px, when text alignment lacks tabular nums for data ledgers, and when spacing scales lack consistency.

Department

UI/UX Interaction

Location

Remote

Compensation

$130,000 – $175,000 USD + Production Hand-off Bonuses
